# Cómo añadir (o quitar) una web

Todo se hace desde el bot de Telegram **[@monitorwebsgh_bot](https://t.me/monitorwebsgh_bot)**, en el móvil o en el ordenador.

## Añadir una web

1. Abre el bot y pulsa **Iniciar** (solo la primera vez).
2. Envíale la dirección de la web, por ejemplo `midominio.com` o `https://midominio.com/`.
   Si quieres ponerle nombre, escríbelo detrás: `midominio.com Mi tienda`.
3. El bot contesta **✅ Añadida** y te dice si ahora mismo funciona.

También puedes pulsar el botón **➕ Añadir web** y luego enviar la dirección.

## Ver tus webs y quitar una

- Pulsa **📋 Mis webs** (o escribe `/webs`): sale cada web con 🟢 si funciona o 🔴 si está caída, el tiempo de respuesta
  y desde cuándo está así.
- Debajo hay un botón **🗑 Quitar …** por cada web; el bot pregunta si estás seguro antes de quitarla.

## Comprobar ahora

Pulsa **🔄 Comprobar ahora** (o `/comprobar`) y el bot revisa todas tus webs en el momento.

## Avisos

- 🔴 **Caída:** cuando una web no responde en 3 intentos seguidos. Te dice el motivo y desde qué hora.
- ✅ **Vuelve:** cuando funciona otra vez, con el tiempo que estuvo caída.
- Se comprueban cada 5 minutos. Cada persona ve solo sus webs (máximo 25).
