Privacidad del bot Monitor webs

Bot de Telegram @monitorwebsgh_bot · actualizado el 7 de noviembre de 2026

Qué guardamos

Solo lo necesario para avisarte: tu identificador de chat de Telegram, las direcciones de las webs que añades y el nombre que les pones, y el estado de cada web (si funciona, desde cuándo y el tiempo de respuesta de la última comprobación). No guardamos tu nombre, tu número de teléfono ni el texto de tus mensajes.

Para qué

Para comprobar tus webs cada 5 minutos y mandarte por Telegram un aviso cuando una se cae y cuando vuelve. Nada más: no hay publicidad, no hacemos perfiles y no vendemos ni compartimos tus datos con nadie.

Dónde

En una base de datos privada de Cloudflare (Cloudflare D1), desde donde funciona el bot. Los mensajes pasan por Telegram, con su propia política de privacidad. Cada persona ve solo sus webs.

Cuánto tiempo y cómo borrarlo

Mientras uses el bot. Si quitas una web en «📋 Mis webs», se borra al momento; cuando nadie vigila ya una dirección, se borra también su estado. Para borrar todo lo tuyo, quita todas tus webs o escríbenos y lo borramos.

Las comprobaciones

Para saber si una web funciona, el bot visita su dirección como lo haría un navegador (se identifica como «MonitorWebsBot»). Solo vigila webs públicas con dominio; no entra en zonas privadas ni guarda el contenido de las páginas.

Contacto

Escríbenos abriendo una incidencia en el repositorio. El código del bot es público: github.com/wpdesigndev/monitor-webs
